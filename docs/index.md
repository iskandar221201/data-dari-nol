## Cara memakai buku ini

Baca berurutan dari **Bab 0**. Setiap halaman SQL diakhiri latihan dengan kunci jawaban. Di Bab 3, kerjakan dulu pre-test-nya sebelum membaca bedahannya, itu bagian dari latihannya. Target akhirnya: kamu bisa mengerjakan studi kasus end to end dan menaruhnya di portfolio.

::: warning Dalam pengembangan
Bab 0 sampai Bab 3 (SQL dasar, SQL lanjutan, 4 studi kasus real) sudah bisa dibaca. Bab 4 sampai Bab 8 masih berupa kerangka dan akan ditulis bertahap. Lihat [Roadmap](/roadmap) untuk rencana pengembangannya.
:::
