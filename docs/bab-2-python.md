## Yang akan dibahas

1. **Kenapa Python**: saat data terlalu besar untuk spreadsheet dan query SQL mulai berulang-ulang.
2. **pandas dasar**: baca CSV, lihat sekilas (`head`, `info`, `describe`), pilih kolom dan baris.
3. **Groupby dan agregasi**: padanan tabel pivot dalam kode.
4. **Gabung tabel**: padanan `JOIN` dan `VLOOKUP`.
5. **Alur kerja yang rapi**: satu notebook = satu pertanyaan, dari data mentah sampai kesimpulan.

## Prinsip bab ini

Python di sini adalah perkakas, bukan tujuan. Kamu tidak perlu jadi programmer dulu untuk memakainya. Setiap konsep langsung dicoba dengan dataset contoh.
